# RateCard mobile app

The Flutter app of the RateCard prototype: sign in with a mobile number, search
a test and compare nearby labs, find a doctor by specialty, book at a partner
hospital, and see your bookings. It reads everything from the API in
`../backend`, so start that first.

```bash
flutter pub get
flutter run -d chrome
```

Setup, screenshots and a walkthrough are in the [prototype README](../README.md).
